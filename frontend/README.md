# Noces

Site d'invitation de mariage. Tout ce qui change d'un mariage à l'autre est dans `wedding.config.ts`.

```bash
npm install
npm run dev
```

Le site s'ouvre sur http://localhost:3000.

- Photos : `public/photos`, puis le chemin dans la configuration (`/photos/hero.jpg`).
- Musiques : `public/music`, puis le chemin (`/music/ambiance.mp3`).
- Lieux : `mapQuery` accepte une adresse ou un lien Google Maps.
- Couleurs du site : `colors`. Couleurs du dress code : `dressCode.colors`.
